# 🛒 Bodega Tony Tony - App de Mini Market

Aplicación de pedidos en línea para mini markets con delivery a domicilio.

## 📁 Estructura del Proyecto

```
BODEGA-Tony-tony/
├── pages/                    # Páginas HTML
│   ├── index.html           # Aplicación principal
│   ├── admin.html           # Panel de administración
│   ├── politica.html        # Política de privacidad
│   └── terminos.html        # Términos y condiciones
├── assets/                  # Recursos estáticos
│   ├── css/
│   │   ├── style.css        # Estilos principales
│   │   └── admin.css        # Estilos del admin
│   ├── js/
│   │   ├── app.js           # Lógica de la app
│   │   └── admin.js         # Lógica del admin
│   └── images/
│       └── logo.png         # Logo de la marca
├── public/                  # Configuración pública
│   ├── manifest.json        # PWA manifest (app)
│   └── manifest-admin.json  # PWA manifest (admin)
├── sw.js                    # Service Worker
├── README.md               # Este archivo
└── .gitignore             # Archivos ignorados
```

## 🚀 Características

- ✅ Catálogo de productos
- ✅ Carrito de compras
- ✅ Integración con WhatsApp
- ✅ Sistema de puntos de cliente
- ✅ Panel de administración
- ✅ Seguimiento de pedidos en tiempo real
- ✅ Chat en vivo
- ✅ PWA (Progressive Web App)

## 🔧 Tecnologías

- HTML5
- CSS3 (responsive)
- JavaScript Vanilla
- Firebase Firestore
- Service Workers (PWA)
